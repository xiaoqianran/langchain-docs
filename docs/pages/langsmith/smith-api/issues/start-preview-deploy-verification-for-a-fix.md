# Start preview-deploy verification for a fix

/langsmith/langsmith-platform-openapi.json post /api/v1/platform/issues/{id}/start-preview
Opens/reuses the fix PR, applies the preview label, and schedules the poll that resumes the fix run when the preview is up.
