    <Update label="July 27-31, 2026">
      ## 可观察性和评估

      ### 数据集和实验

      * LangSmith 公开注释队列项端点，用于通过公共 API 和 SDK 生成流程添加、列出、更新、删除、计数、定位和查看运行或线程队列项。
      * 现在，无论浏览器报告的内容类型是什么，都可以上传 .csv 或 .jsonl 数据集。 Windows 浏览器将 .csv 文件标记为 Excel 类型，这此前会导致有效上传失败。也接受大写文件名，例如 DATASET.CSV。
      * 数据集或跟踪项目上的评估器列表现在显示评估器的当前名称，而不是附加时的名称。重命名后反馈键不会发生变化。* 实验比较网格中的元数据列（包括 `example.metadata.<key>`）现在呈现其值而不是保持为空。
      * LangSmith 将 SmithDB SDK 迁移指南替换的每个旧端点标记为已弃用：v1 运行查询和检索端点、v1 运行共享和公共运行读取端点、`POST /api/v1/datasets/{dataset_id}/runs` 以及注释队列运行端点。现在，所有这些都使用 `Deprecation: true`、2027 年 1 月 31 日的 `Sunset` 日期以及指向迁移指南的 `Link` 标头以及（如果存在单个替换）后继端点进行响应。 [Learn more](/langsmith/smithdb-sdk-migration)。
      * 当启用 SmithDB 查询并禁用 ClickHouse 查询时，数据集实验表可以按反馈分数排序。
      * 注释队列项 API 使用project\_id 来跟踪项目。请求主体还接受 session\_id 作为别名。
      * 数据集示例视图恢复示例详细信息和选项卡导航之间的清晰间距。
      * 成对注释队列再次运行，包括禁用 ClickHouse 查询支持时创建反馈所需的跟踪项目 ID。* 现在，从实验结果网格中更正评估器分数会立即更新单元格及其弹出窗口，而不需要刷新页面。
      * 配置评估器窗格的标题和模板导航再次在深色模式下绘制与窗格本身相同的背景。
      * 数据集和运行附件现在可以在自托管部署中预览、打开或下载之前解析相对签名的下载 URL。

      ### 监控和警报

      * 将可重复使用的 ChartCard 组件添加到 LangSmith 设计系统中，标准化图表标题、移动、展开和溢出操作、响应式全角布局以及图表和图例间距。

      ＃＃＃ 引擎* 现在，一旦引擎将新的匹配跟踪链接到引擎问题板上，引擎问题板上已解决的问题就会返回“打开”。此前，跟踪记录已作为证据归档，但该问题一直处于关闭状态，因此出现的问题从未在主板上重新出现。被驳回的问题仍被驳回。
      * 问题详细信息标题现在将类别和标签徽章呈现在与标题相同的行上，而不是将它们堆叠在下面，从而收紧标题并减少垂直空间的浪费。
      * 在问题板上配置 Slack 通道或 Webhook 目标时，不再提供“引擎未能完成运行”触发器。已订阅的目的地会继续收到这些通知。
      * 引擎运行的 webhooks 和沙箱链接现在解析从 LANGSMITH\_PUBLIC\_API\_ENDPOINT 外部可访问的 API 库，回退到 LANGCHAIN\_PLATFORM\_ENDPOINT，然后是 LANGCHAIN\_ENDPOINT。其图表集仅 LANGSMITH\_PUBLIC\_API\_ENDPOINT 正在构建相对 URL 的安装，这使得每个非影子引擎运行失败，因为运行 Webhook 作为环回地址被拒绝。

      ### 追踪* 跟踪详细信息窗格再次使用与其部分标题相匹配的升高背景。
      * 批量导出接受新的选择加入 `feedbacks` 列，该列以 JSON 数组的形式承载每次运行的单独反馈条目及其键和注释。创建导出时将`feedbacks`添加到`export_fields`；省略 `export_fields` 的导出保留其现有列。
      * 确认破坏性操作后，从运行详细信息操作菜单中删除整个跟踪。
      * 当 ClickHouse 使用优化的运行表时，负反馈键过滤器现在可以正确返回匹配跟踪。
      * 当项目配置自定义输出渲染器时，跟踪输出部分现在将其作为自定义选项与 Markdown、Plain、JSON 和 YAML 一起提供，而不是替换它们。自定义保持默认状态，并且您的选择会被记住。
      * 使用 6.2 之前的 Redis 版本跟踪项目活动并排序以保持最新的自托管部署。* 现在，当您的工作区中不存在所请求的跟踪项目时，`POST /api/v1/runs/stats` 返回 404，并报告其他客户端错误，例如早于支持的回溯窗口的 `start_time`，以及其真实状态和消息，而不是通用的 500 内部服务器错误。
      * 自托管部署现在可以弥补丢失的跟踪项目上次运行时间戳，因此项目排序可以反映最近的历史活动。
      * 运行过滤器现在支持跨路由查询后端一致的总数、提示和完成令牌计数和成本。
      * 令牌计数/成本过滤器现在默认为总令牌/成本，而不是输入令牌。输入和输出令牌/成本细分在选择器中仍然可用。
      * 在跟踪项目中，重置视图现在会将线程/跟踪/运行切换器与显示的行同步移动。以前，当表已经返回到跟踪时，切换器可以保持在运行状态。

      ＃＃＃ 反馈* 注释队列项端点现在记录在 /api/v1/platform 下的服务路径中，因此生成的用于列出、添加、更新、计数、删除和放置队列项的 SDK 方法将到达 API，而不是返回 404。
      * 附加到消息的 PDF 和其他文档现在呈现在全宽预览框架中，并带有标题控件，可以几乎全屏打开它们，而不是折叠到缩略图大小的框。

      ### 提示和游乐场

      * 当模型提供者拒绝 Playground 运行时，例如错误的 API 密钥或耗尽配额，Playground 现在会显示提供者自己的错误消息，而不是通用服务器错误，因此从错误本身可以清楚地看出原因。
      * Playground 批处理和调用端点现在在响应之前将缓冲的运行树清理为 JSON 安全的有效负载，因此当运行图无法序列化时，在线评估不再因不透明 500 而失败。

      ### 自动化* 分叉评估器会将副本附加到分叉对话框中指定的项目或数据集。以前，可以创建不附加任何内容的副本，让原始评估器运行您刚刚编辑过的版本。

      ## 部署

      * 当提交的值验证失败（例如无效的图像路径）时，“创建新部署”表单现在会显示清晰的每个字段消息，而不是原始后端错误负载。
      * 现在，删除 LangGraph 部署仍在其删除后保留窗口内的跟踪项目会计划将项目与部署一起删除，并在错误消息中进行解释，而不是要求您删除已删除的部署。
      * LangGraph 部署的删除确认现在表明，在您确认后将运行底层数据库的清理，并且已删除部署的名称将保持保留状态，直到清理完成。

      ## 沙箱* 对于无法持有 WebSocket 的客户端，沙箱接受新的流式执行请求，该请求将 stdout 和 stderr 作为服务器发送的事件返回。传递命令 ID 重用正在运行的命令，单独的恢复请求会继续中断的流，而不是再次运行该命令。
      * 沙箱现在在 PATH 上附带 `langsmith` CLI，因此代理可以查询跟踪、运行和数据集，而无需先安装它。
      * 沙盒和快照行现在使用单列布局，并在上下文菜单中执行操作，快照源在其菜单中仍然可用，并且包装名称保持左对齐。
      * 自托管部署中的引擎沙箱命令现在使用部署服务密钥通过 WebSocket 进行身份验证，从而防止成功创建沙箱后出现 401 失败。
      * 沙盒中的`langsmith` CLI 已更新至 v0.2.44。它的请求现在在为 `/api` 下的 API 提供服务的自托管部署上解析，其中 `trace messages` 等命令和项目问题命令之前失败。

      ＃＃ 行政* LangSmith 主页现在提供快速访问以复制当前组织和工作区 ID。
      * 在使用 OAuth/SSO 进行身份验证的自托管安装中，远程 MCP 授权端点返回 400，因为 SSO 登录路由对其进行了隐藏。 OAuth 客户端现在可以完成授权步骤并连接到远程 MCP 服务器。
      * 具有在线许可证密钥（信标访问）的自托管部署现在可以自动查看每月组织使用情况图表，无需启用\_monthly\_usage\_charts 组织配置。离线部署现在指向“粒度使用”选项卡，以获取本地记录的计费使用情况。
      * 当路线没有特定于工作区的资源 ID 时，切换工作区或组织可让您保持在同一页面上。引用特定资源的路由将继续打开目标工作区主页。
      * LangSmith 现在会刷新过期的浏览器会话，并在要求您再次登录之前重试中断的 API 请求。

      ### 法学硕士网关* 具有空白或仅空白名称的网关策略现在会回退到显示策略 ID，而不是呈现空名称单元格，并且策略更新端点现在会像创建时一样拒绝空白名称。
      * 网关使用支出图表现在显示每个存储桶中排名前 12 位的个人支出者，将其余的滚动到“其他”系列中，其悬停工具提示会立即列出每个贡献者，并将存储桶总额固定在其下方。
      * 主页登录流程现在包括一个选择代理如何达到模型的步骤：携带您自己的提供商 API 密钥，或使用 Gateway Credits。选择网关积分可让组织管理员预先购买预付费积分，并显示开始发送流量所需的 API 密钥和网关 URL，无需提供商帐户。
      * LLM 网关支出上限和速率限制策略上的自定义 X-Gateway-\* 标头条件现在也适用于组织、工作区和用户范围的策略，而不仅仅是 API 密钥范围的策略，因此您可以按标头值将单个主题的流量拆分为单独的上限，而不管策略的范围如何。* LLM Gateway 中的默认支出上限和速率限制策略现已扩展，以显示在其下具体化的每用户、每工作空间和每 API 密钥策略。
      * Gateway Credits 购买对话框现在会显示您购买时将获得的积分余额，并在单次购买按钮上方直接注明含费用总额。大金额不再将学分读数和总数推到对话框之外。
      * 没有数据保护的企业组织现在可以在 LLM 网关中看到该选项卡，该选项卡呈灰色并带有请求访问的链接，而不是完全隐藏该选项卡。

      * Gateway Home 代码示例现在使用为每个 LangSmith 区域构建的网关主机名，并默认为支持的响应 API。 [Learn more](/langsmith/llm-gateway)。

      * 家庭登录步骤现在以美元显示您的 Gateway Credits 余额，与您购买的金额相匹配，而不是将其转换为 LCU。
      * 现在，您在入职期间复制到编码代理中的提示将说明代理应如何根据您选择的提供商访问模型：Gateway Credits 或您自己的提供商 API 密钥。* 主页间距和表面着色现在与设计审核反馈相匹配，并且几个小文本修复阐明了信用限额、提供商状态和组织级购买限制。

      * LLM Gateway Home 现在突出显示所选模型，并允许您在聊天完成、消息和响应格式之间切换连接示例。

    <Update label="July 20-24, 2026">
      ## 可观察性和评估

      ### 数据集和实验* `GET /annotation-queues/{id}/items` 现在返回 THREAD 队列项目和 RUN 项目，并带有可选的 item\_type 过滤器。 THREAD 列表行公开项目上的标识（thread\_id/session\_id/start\_time）并省略嵌套线程； RUN 列表目前仍然支持嵌套运行（与仅元数据列表计划相同的省略）。查看时，跟踪和消息通过 v2 线程 API 加载。
      * `GET /annotation-queues/{id}/runs` 和相关大小端点排除 THREAD 队列行（run\_id 为 null），因此混合队列不再返回 500。使用 GET /items 进行线程列表。
      * 项目设置现在需要至少两分钟的线程空闲时间，以确保线程评估包括所有摄取的运行。
      * 注释队列项目添加请求现在始终对运行和线程强制执行 100 项限制。超限错误清楚地显示配置的限制。
      * `GET /annotation-queues/{id}/items` 返回 RUN 和 THREAD 项的 Postgres 成员资格元数据，而不从 ClickHouse 或 SmithDB 中水合嵌套运行或线程有效负载。孤立队列行仍保持列出状态。 include\_stats 查询参数已删除。通过 get-one / review API 注释有效负载负载。* 当您从跟踪项目批量添加运行时，其默认数据集现在首先出现在数据集选择器中。
      * 注释队列审查列表现在将未命名的运行行标记为 `Run <ID>`，匹配线程行并使混合队列更易于扫描。
      * 当两个比较的运行来自同一实验时，从成对注释队列打开成对实验比较不会再导致页面崩溃。

      ### 追踪

      * 见解报告窗格现在可以折叠，为报告详细信息提供更多空间。
      * 见解集群摘要列现在可以展开以显示每个摘要的更多信息。
      * 当为获取的运行记录该值时，LangSmith MCP 的 `fetch_runs` 工具现在会返回 `first_token_time`，无需单独的 SDK 查询即可进行 TTFT 分析。
      * 旧版运行 URL 现在解析运行元数据并重定向到 SmithDB 跟踪视图，而不是显示错误。
      * 跟踪使用限制横幅现在仅针对已超出用户范围限制的工作区成员显示。
      * 跟踪项目页面上的部署按钮现在可在应用程序内打开部署页面，而不是重新加载 UI。* 单击线程跟踪树中已选择的运行或跟踪现在可以使其保持选中状态，而不是取消选择它并滚动回第一个跟踪。
      * 修复了两个前端调用站点，它们可能会在会话为空或丢失的情况下到达 POST /runs/stats，从而防止 Insights 作业配置和会话规则表单中出现虚假 422 错误。
      * MCP 运行查询工具现在无需重试即可返回网关超时响应，从而减少运行查询超时时的重复负载。
      * 现在，在 LangSmith Chat 中按 Enter 键确认输入法编辑器中的字符（例如中文拼音或日文/韩文输入法）会提交撰写的文本，而不是过早发送消息。
      * LangSmith Chat 现在在读取跟踪的 LLM 运行时内联显示运行的系统提示，因此它可以解释为什么模型以某种方式运行而不会错过系统提示。它还识别存储为提供者级字段的系统提示（OpenAI Responses `instructions`、Anthropic `system`）。
      * LangSmith 聊天跟踪现在显示您配置的模型，而不是在使用自定义模型端点时将其错误标记为 GPT-3.5-Turbo。*“在 Studio 中运行”按钮现在隐藏在公共（共享）运行页面上，该按钮之前指向共享查看器无法打开的经过身份验证的页面。
