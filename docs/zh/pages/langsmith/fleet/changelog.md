## 舰队

- 连接 Google 现在可以授予舰队代理访问您自己的文档、表格和幻灯片的权限，而不仅仅是代理自行创建的文件。现有连接保持不变；从集成页面重新连接 Google 以授予更广泛的访问权限。
- 您现在可以在聊天中附加 .docx、.xlsx 和 .pptx 文件，而无需为代理提供沙箱。接受文档输入的模型，例如OpenAI和Gemini，直接读取文件。
- 支持沙箱的 Fleet 代理现在将 PPT 请求视为 PowerPoint 可交付成果，并创建 .pptx 文件而不是 HTML 演示文稿。
- 支持沙箱的 Fleet 代理可以创建电子表格、修改现有工作簿以及回答有关 .xlsx 和 .xlsm 文件的问题，而无需先安装电子表格工具。内置技能可指导安全使用 openpyxl 并在交付前验证每个工作簿。- 当客服人员轮流工作时，聊天现在会显示实时经过时间计数，该计数会在几秒钟后出现，并在等待时间较长时拾取旋转状态标签，因此慢速轮流会被视为正在进行中而不是停止。一旦答案到来，流式推理模型仍然会崩溃到它们思考的时间。
- 舰队代理现在可以使用 Google Drive，搜索、组织、共享和检查文件，并获得其他表格、幻灯片、文档、日历、Gmail 和 Meet 操作，例如回复和转发电子邮件、回复邀请以及检查空闲/忙碌时间。
- Fleet 现在使用选定的用户身份来处理未绑定到特定存储库的 GitHub 请求。
- 自定义 Slack 应用程序可以选择订阅所有新频道消息，而不仅仅是@提及。启用后，代理会收到每条消息，并仅在有帮助时进行回复。
- 舰队现在将选定的工件元素显示为反馈芯片，而消息在活动运行期间排队。- 支持沙箱的 Fleet 代理可以将旧版 Office、OpenDocument、RTF、EPUB 和基于文本的 PDF 文件转换为 Markdown 以便阅读和提取。内置技能可引导现代 Office 文件并直接支持 PDF 到其现有工作流程。
- 当代理读取其模型无法接受的文件作为附件时，Fleet 现在会替换一个简短的解释，而不是使请求失败。之前陷入困境的对话将恢复到下一条消息。
- 从本地文件夹创建舰队技能，同时保留其 SKILL.md 和支持文件。
- 技能文件夹上传现在最多接受 500 个文件，与 API 支持的文件相匹配，并在阅读时报告进度。太大或包含非文本文件的文件夹将被预先拒绝并指定特定文件。

</Update>

- 在边缘到边缘的工作区中打开聊天文件，然后将它们折叠回“文件”侧面板，而不会丢失您的位置。

- 附加到 Slack 消息的文件现在可在 /workspace/uploads 下用于沙箱支持的代理，匹配从 Fleet 上传的文件。
- 单击“工作区代理”中的“+ 新代理”现在会打开与 Fleet 中其他地方使用的相同“新代理”对话框，而不是旧的草稿编辑器。
- 当代理详细信息仍在加载时，导航到与所选代理的代理聊天不再崩溃。聊天显示加载状态，直到代理准备就绪，然后正常呈现。
- 沙箱支持的舰队代理可以创建或修改可下载的 DOCX 文件，而无需在任务期间安装创作包。内置技能指导文档创作和结构验证。- 配置面板现已对所有人启用，因此当您打开代理时，它始终显示在聊天旁边。
- Fleet 现在仅解析 Bedrock 模型的 AWS IAM 角色，因此加载 OpenAI 和其他提供商机密不再等待 AWS STS。
- 新的代理创建体验现已向所有人开放。向助手询问代理会显示“创建代理”按钮，新代理会运行自己的设置对话，而不是内联构建。
- 存储状态超过 API 通常的单一响应大小限制的对话现在可以完整加载，最多 32 MiB，而不是失败。响应将对话标记为过大，并且对其更新仍然会失败，直到其状态缩小。
- 支持沙盒的 Fleet 代理可以构建新的牌组、修改现有的牌组并回答有关 .pptx 文件内容的问题，而无需先安装演示工具。内置技能可指导创作并在交付前验证文件。
- 队列代理可以使用 slack_send_file 和 slack_send_file_to_user 将工作区文件发送到 Slack 通道、线程和直接消息。- 舰队代理现在可以正确地将沙箱创建和组织配置请求路由到自托管部署上的 Go 平台后端服务，其中 Go 和 Python 服务在不同的地址上运行，从而无需反向代理解决方法。

</Update>

## 舰队

- 在运行仍在进行时重新打开或重新加载代理聊天线程不会再导致聊天视图崩溃。聊天显示加载状态，直到代理准备就绪，然后恢复流式传输活动运行。
- 车队使用情况仪表板现在显示具有每月 LangChain 单位 (LCU) 支出限制的组织的仪表，将本月至今的消耗与限制和任何超额进行比较。
- 配置有 Arcade 标头（API 密钥）身份验证的 Arcade MCP 网关无法再添加到队列工作区，因为 LangSmith 通过 OAuth 连接到 Arcade 网关。这些网关现在解释了如何使用 Arcade Auth 或用户源重新配置它们，而不是在您尝试连接时失败。
- 舰队现在将座席卡操作标记为“配置”，与聊天视图中的操作相匹配。- 当 Google 文档、表格、云端硬盘或幻灯片工具无法打开文件（403 或 404）时，代理现在解释说它只能访问使用其连接的 Google 帐户自行创建的文件，而不是错误地指出该文件不存在。
- 当 Google 文档、表格、云端硬盘或幻灯片工具遇到 403 或 404 错误时，Fleet 现在会显示一条警告（在聊天中内嵌在失败的工具调用上方，并在 Slack 中显示为一条消息），解释代理只能访问其通过连接的 Google 帐户自行创建的文件。
- 舰队的配置面板现在显示连接格式选择器，以便您可以选择代理是否使用共享帐户或每用户帐户。
- 连接到 Slack 的代理现在可以使用新的 slack_send_file 工具将文件从其工作区发送到 Slack 通道，例如代理生成的报告、导出或图表。文件上传到服务器端，代理永远看不到 Slack 令牌。
- 当线程状态更新时，包括当用户在聊天中继续触发启动的对话时，队列代理会保留 DeltaChannel 对话历史记录。- 队列线程 API 现在可以包含当前代理的 ID 和名称，从而使线程列表和详细信息更易于显示，而无需获取完整的代理记录。
- 使用 Slack 文件工具的舰队代理现在可以从线程范围和代理范围的沙箱工作区发送文件。

</Update>

## 舰队

- 在 Agent Builder 视图中，页脚工作区和租户列表源自 Fleet API，因此您可以在 Fleet 工作区之间切换。
- 聊天中的 [Access Profiles](/langsmith/fleet/computer-use) 对话框现在包含一个创建访问配置文件链接，该链接可打开沙箱创建流程，因此您可以在工作区未配置任何配置文件时添加配置文件，而不是陷入死胡同。
- 舰队代理现在可以使用新的删除工具从内存和[skills](/langsmith/fleet/skills)删除文件，包括链接工作区技能中的文件。核心代理文件和只读系统技能仍然受到保护。
- Fleet 现在为 [MCP servers](/langsmith/fleet/remote-mcp-servers) 完成 OAuth，其授权服务器需要在令牌端点进行客户端秘密身份验证，因此在同意步骤后连接这些服务器不再失败。- 首次使用 Fleet 的用户现在会看到一个简化的欢迎模式，具有两个清晰的路径（描述使用 AI 构建的代理，从聊天中的提示开始，或从策划的模板开始），取代了以前的多步骤设置向导。
- 从舰队[template](/langsmith/fleet/templates)创建代理现在会跳过设置向导并使用模板入职卡打开代理编辑器。
- 舰队现在发送服务器在握手期间协商的 MCP 协议版本（无论是在加载工具时还是在代理调用工具时），因此需要较新版本的 MCP 服务器不再返回零工具或使工具调用失败。
- 车队代理会收到星期几以及当前日期（例如“2026 年 6 月 29 日星期一”），因此调度和日期推理不再依赖于从 ISO 日期推断工作日的模型。
- 舰队代理聊天中的文件编辑现在呈现为语法突出显示的逐行差异，使更改更易于查看。
- 舰队特工现在可以读取 [Slack](/langsmith/fleet/slack-app) 中与他们共享的文件。在提及或 DM 中附加图像、PDF、音频、视频或文本文件，然后代理将其引入对话中。- 在“Agent Builder 集成”页面上，搜索现在会选择“全部”选项卡，因此结果涵盖每个类别，并且切换类别选项卡会清除搜索。
- 当您将自定义 [Slack](/langsmith/fleet/slack-app) 机器人连接到 Fleet 代理时，Fleet 会向安装人员发送一条直接消息，其中包含快速设置提示，包括如何将机器人添加到频道并使用 @ 提及它。
- 舰队代理现在有一个 Slack 工具，用于列出连接的机器人所属的频道，从而可以在发布或阅读消息之前更轻松地发现正确的频道。
- 队列 OAuth 提供程序和集成响应现在包含 `owner` 字段（`workspace` 或 `platform`），以便您可以区分自己的资源和内置的、平台管理的资源。平台管理者组织现在可以创建和修改内置 OAuth 提供程序。
- 设置 [schedule](/langsmith/fleet/schedules) 现在更加清晰：选择预设（每日、每周、每月或每隔几分钟）或输入自定义 cron 表达式，并随时提供人类可读的实时预览和内联验证。- 为无头连接注册集成 OAuth 提供程序时，现在仅接受环回 IP 文字 `127.0.0.1` 或 `[::1]` 的 `http://` 重定向 URI。 `http` 不再接受 localhost 主机名；使用环回 IP 文字或`https`。
- 当指针位于服务器列表上方时，[MCP servers](/langsmith/fleet/remote-mcp-servers) 设置页面现在会滚动。
- 加载以前的对话工具现在在启用时将对话文件写入附加的计算机沙箱，因此代理可以使用普通文件工具检查下载的历史记录。
- 当舰队代理的子代理调用需要人工批准的工具时，批准提示现在会出现在聊天中，而不是在没有它的情况下完成运行。
- 连接 Slack 工作区后，行政助理模板现在可以在[Slack](/langsmith/fleet/slack-app) 中提供每日简报和回答@提及，并且行政助理和软件工程师模板都收到了配置修复。
- 现在，当人机交互提示处于待处理状态时，您可以在代理聊天中键入并发送消息。发送新消息会驳回待处理的请求并继续对话，而不是让撰写者处于锁定状态。- 代理配置面板中的空白部分（通道、连接、技能、计划、说明和子代理）现在解释了每个部分的用途以及在连接任何内容之前可以添加的内容。
- 当聊天流返回字符串消息内容时，创建新代理不再因 contentBlocks.push 错误而失败。
- 在聊天收件箱中打开代理在选择要打开的线程时不再发出重复的后台请求，从而减少了闪烁。
- 舰队代理现在加载您工作空间的私人[skills](/langsmith/fleet/skills)。以前，在具有细粒度访问控制的工作空间中，代理只能从可用的公共技能开始。
- 重新加载代理聊天页面不再通过加载和加载状态多次闪烁线程列表。现在，侧边栏在获取线程之前等待代理作用域完成加载，因此列表会稳定一次。
- GitHub 应用程序安装现在在安装完成后通过经过身份验证的 LangSmith 会话同步，使工作区链接与活动用户保持一致。- OAuth 提供商现在接受可选的默认重定向 URI (`default_redirect_uri`)。设置后，该提供程序的无头 OAuth 流会向其返回授权代码，而不是 LangSmith 回调，而无需在每个请求上传递重定向。该值根据提供程序允许的重定向 URI 进行验证。
- 舰队代理现在在打开工具的参考文档之前使用 find_tools 或 /tools 列表发现工具，因此他们不再浪费时间阅读不存在的猜测工具文件名。
- Fleet Fast 模型层 (`gpt-5.4-mini`) 现在以中等推理速度（而不是低推理速度）运行，从而提高了较难任务的响应质量。
- [templates](/langsmith/fleet/templates) 库现在以带有英雄插图的大卡片形式提供执行助理和软件工程师模板，每个模板都显示代理自己的图标。
- 代理配置面板中连接内的每个工具现在都有删除操作（悬停时显示的垃圾按钮，与连接删除相匹配），而不是开/关开关。该开关意味着可逆切换，但关闭工具实际上会将其从代理中删除，因此控件现在反映了它的作用。- 在澄清悬而未决的问题时发送聊天消息可能会导致运行失败并导致线程卡住。现在，自由文本会在继续之前正确地驳回待处理的请求。
- 在 Agent Builder 聊天中，技能块的“添加技能”菜单现在可打开浏览工作区、创建技能和从 URL 导入对话框。之前选择的选项更改了 URL，但没有出现任何内容。
- 现在在舰队中打开代理总是会开始新的聊天，而不是跳到最近的线程。过去的对话仍然可以在线程侧栏中找到。
- 当从模板创建的代理进行自我介绍时，它会将学到的内容直接写入自己的内存中，而不是暂停以等待每个文件的批准。其他线程中的内存写入仍然首先询问。
- 包含引号、冒号或多行的技能描述现在可以正确解析和存储，并且导入或编辑技能会保留其所有 frontmatter，而不是删除许可证或允许的工具等字段。
- 添加连接对话框现在将 Arcade MCP 服务器分组在专用 Arcade 部分下，因此它们很容易找到，而不是列在“其他”下。- 舰队模型选择器现在将服务的 LCU 计费模型（Fast、Pro、Max）与按运行计费的自带模型分开进行分组，从而使每个选项的定价模型更加清晰。
- Agent Builder 中的紧凑型 Fast/Pro/Max 模型选择器现在在其关闭的触发器上显示模型图标，与完整模型选择器相匹配。
- 当组织达到其每月舰队使用限制时，错误现在会指示用户升级其计划以继续。

## 新功能

- 您现在可以一键将任何代理添加到[Slack](/langsmith/fleet/slack-app)。使用 Slack 进行一次身份验证后，Fleet 会自动创建一个配置有代理名称、描述和图标的 Slack 应用程序，并将每个代理映射到单个 Slack 应用程序。
- 当代理首次添加到 Slack 工作区时，它会向创建者发送一条直接消息，其中包含邀请其加入频道并提及的提示。
- 客服人员现在可以直接在[Slack](/langsmith/fleet/slack-app)中提出工具批准，并在线程中使用“批准”和“拒绝”按钮，因此您不再需要切换到 Fleet UI 来响应。
- 当代理在运行期间遇到错误时，它现在会在 Slack 线程中进行回复，而不是保持沉默。身份验证错误和其他一些错误类型包含更多详细信息。- 代理现在可以读取 [Slack](/langsmith/fleet/slack-app) 消息中的文件附件。
- 代理编辑器现在是代理聊天页面中内置的侧边栏，它将配置组织到频道、连接、知识、计划和高级设置抽屉中。
- 代理创建体验现在从一个空白的代理开始，该代理会自行配置并在关键点暂停以带您进入该过程。

</Update>

- 舰队代理现在可以读取在 Slack 中与他们共享的文件。在提及或 DM 中附加图像、PDF、音频、视频或文本文件，然后代理将其引入对话中。- 在“Agent Builder 集成”页面上，搜索现在会选择“全部”选项卡，因此结果涵盖每个类别，并且切换类别选项卡会清除搜索。
- 当您将自定义 Slack 机器人连接到 Fleet 代理时，Fleet 会向安装人员发送一条直接消息，其中包含快速设置提示，包括如何将机器人添加到频道并使用 @ 提及。
- 舰队代理现在有一个 Slack 工具，用于列出连接的机器人所属的频道，从而可以在发布或阅读消息之前更轻松地发现正确的频道。
- 队列 OAuth 提供程序和集成响应现在包含 `owner` 字段（`workspace` 或 `platform`），以便您可以区分自己的资源和内置的、平台管理的资源。平台管理者组织现在可以创建和修改内置 OAuth 提供程序。
- 设置时间表现在更加清晰：选择预设（每日、每周、每月或每隔几分钟）或输入自定义 cron 表达式，并提供实时人类可读预览和内联验证。- 为无头连接注册集成 OAuth 提供程序时，现在仅接受环回 IP 文本 `127.0.0.1` 或 `[::1]` 的 `http://` 重定向 URI。 `http` 不再接受 localhost 主机名；使用环回 IP 文字或`https`。
- 当指针位于服务器列表上方时，[MCP servers settings page](/langsmith/fleet/remote-mcp-servers) 现在会滚动。
- 当舰队代理的子代理调用需要人工批准的工具时，批准提示现在会出现在聊天中，而不是在没有它的情况下完成运行。
- 连接 Slack 工作区后，行政助理模板现在可以在 Slack 中提供每日简报和回答@提及，并且行政助理和软件工程师模板都收到了配置修复。
- 现在，当人机交互提示处于待处理状态时，您可以在代理聊天中键入并发送消息。发送新消息会驳回待处理的请求并继续对话，而不是让撰写者处于锁定状态。
- 代理配置面板中的空白部分（通道、连接、技能、计划、说明和子代理）现在解释了每个部分的用途以及在连接任何内容之前可以添加的内容。- 在聊天收件箱中打开代理在选择要打开的线程时不再发出重复的后台请求，从而减少了闪烁。
- 舰队特工现在加载您工作空间的私人技能。以前，在具有细粒度访问控制的工作空间中，代理只能从可用的公共技能开始。
- GitHub 应用程序安装现在在安装完成后通过经过身份验证的 LangSmith 会话同步，使工作区链接与活动用户保持一致。
- OAuth 提供商现在接受可选的默认重定向 URI (`default_redirect_uri`)。设置后，该提供程序的无头 OAuth 流会向其返回授权代码，而不是 LangSmith 回调，而无需在每个请求上传递重定向。该值根据提供程序允许的重定向 URI 进行验证。
