## 亮点

* **重新连接停止工作的 OAuth 帐户**：当 OAuth 令牌无法再刷新时，Fleet 现在会显示 **需要重新连接** 徽章和 **重新连接** 按钮，而不是 **已连接**。在帐户对话框中，**重新连接**会重新授权同一帐户，而不是添加第二个帐户，并且会保留代理连接，以便在您重新连接后它们会再次工作。代理运行还会跳过令牌未激活的服务器，令牌和连接响应包括`status`和`status_reason`。 [Learn more](/langsmith/fleet/remote-mcp-servers)。

## 舰队* 当代理在线程中工作时，Slack 通道运行现在显示 Slack 的本机停止按钮，因此您可以停止从 Slack 启动的运行。停止运行会在线程中发布带有您姓名的“停止”并清除工作状态。
* Slack 现在可以在运行时显示运行进度：“停止”按钮旁边有一条流式消息，其中包含思考步骤、每个工具调用的卡片以及写入的回复文本，因此 Slack 代理会话应用程序不再仅在整个运行过程中显示“正在运行...”。
* 您现在可以将您创建并拥有的 Slack 应用程序连接到自托管部署。使用应用程序的机器人令牌和签名密钥进行部署，触发服务器会存储它们并在重新部署时保持通道处于活动状态，而无需重新发送它们。带有“停止”按钮的代理视图适用于拥有 `assistant:write` 范围的客户拥有的应用程序。
* 现在，您可以在创建代理时为代理选择计算机环境，或者保留该选择以使用工作区默认值。通过读取、克隆和编辑来保留选择，并且代理的 PATCH 可以更改它或将其返回到工作区默认值。* **每用户** 连接选项现在在代理创建和配置面板中标记为 **推荐**，导入的代理将保留保存时使用的连接格式。
* 自定义工作区 MCP 服务器现在显示在 **托管工具** 选项卡和 **添加连接** 选择器中以及 LangSmith 内置服务器中，因此您可以从任一位置将它们连接到代理。
* 发布 Slack 反馈按钮的客服人员现在会收到对其回复的“赞成”和“反对”点击，因此您的客服人员可以根据评分采取行动。您的部署收到的事件中不再包含 Slack 的验证令牌。
* 当 Slack 机器人背后的代理被存档、删除、取消链接或暂时无法访问时，机器人现在会在一条短暂的消息中回复发件人，说明出了什么问题以及谁可以修复它，而不是保持沉默。在频道中，机器人仅在提及时回复。
* 您现在可以通过电子邮件过滤用户使用情况报告。将 `email` 查询参数传递给 `GET /v1/fleet/usage/users` 以仅返回匹配的用户，因此您不再需要翻阅工作区中的每个用户。匹配会忽略字母大小写和周围的空格，长度超过 254 个字符的电子邮件将返回 400 错误。* 代理身份验证应用程序现在可以是线性 OAuth 应用程序：使用提供程序 `linear` 和源 `existing` 创建一个应用程序，传递 `client_id`、`client_secret` 和 `scopes`，并通过应用程序连接上的会话安装它。

## 亮点* **将 MCP 客户端连接到 Fleet 代理**：每个 Fleet 代理现在都是 MCP 服务器，因此 Claude Code 和 Cursor 等客户端可以使用您的 API 密钥和工作区标头在 `/v1/fleet/agents/{agent_id}/mcp` 向其交付任务。端点公开`send_message`、`respond_to_interrupt`、`get_thread`和`cancel_run`，因此客户端可以开始对话、应答中断、检查长时间运行和停止运行。队列 API 参考现在记录了端点及其请求正文。 [Learn more](/langsmith/fleet/code)。
* **通过 A2A 呼叫车队代理**：每个车队代理现在都可以在 `POST /v1/fleet/agents/{agent_id}/a2a` 作为 A2A 服务器，并在 `GET /v1/fleet/agents/{agent_id}/.well-known/agent-card.json` 拥有代理卡。将任何 A2A 客户端指向 `/v1/fleet/agents/{agent_id}` 作为其基本 URL，并将 `SendStreamingMessage` 用于长时间运行的代理。没有 `contextId` 的消息会启动一个新的 Fleet 线程，共享代理会看到调用它们的人的身份。 [Learn more](/langsmith/fleet/code)。

## 舰队* Slack 代理现在可以在没有 @-mention 的情况下回答线程中的后续回复：在创建频道时将 `triggerMode` 设置为 `thread`，或者就地更改现有 Slack 频道的模式，并且应用程序会更新其事件订阅而无需重新安装。新 Slack 通道的默认设置保持为 `mention`，现有通道保持其当前模式，直到您更改它。
* 需要 API 密钥的聊天模型现在会显示该密钥是否已配置，保持可见但在丢失时禁用，并从模型菜单中打开 **配置 API 密钥** 对话框，以便您可以添加密钥而不会丢失聊天选择。
* 车队客户现在可以从新的 `/v1/fleet/usage/users` 和 `/v1/fleet/usage/agents` 端点按用户和代理获取预估的美元成本，并使用光标分页（`page_size` 最多 100）并按成本、运行次数或首次和最后一次使用进行排序；端点需要`fleet:read-admin-config`权限。
* 秘密 MCP 服务器现在在未存储密钥时显示一个用于输入 API 密钥的链接，因此工具调用会返回一个登录式链接来添加它，而不是死胡同；同一链接还允许您替换轮换或撤销的密钥，并且保存的值将作为其标头在下一个请求中发送。* 免费工作区现在创建新的舰队代理和构建代理，并使用状态存储而不是沙箱，并且免费计划上的新常规聊天将附加文件保持在图形状态。计算机访问仍可作为升级选项使用，付费计划保留现有的后端选择。
* 代理配置面板现在是一个覆盖聊天的模态抽屉，**保存更改**始终在页脚中可见；它会在成功保存后关闭，并在关闭未保存的编辑时要求您在放弃它们之前进行确认。
* Web UI 中的 Slack 触发线程现在显示 Slack 卡，其中包含发件人姓名、消息文本和“在 Slack 中打开”链接，而不是代理收到的原始通道 ID 和用户 ID。消息中提及的用户显示为其姓名。在此更改之前创建的线程仍然使用卡片打开，但显示发件人的原始 ID 并且没有链接。
* 访问配置文件现在位于 Fleet 中探索部分末尾的新 **计算机** 项下，旧的集成 > 计算机链接重定向到新页面。* 队列计划现在要求至少五分钟的分钟间隔，因此低于 5 分钟的每分钟和通配符步骤（例如 `*/3`）将被拒绝，并显示一条建议 `*/5 * * * *` 的消息。
* 新的构建代理现在默认为每用户连接并记录跟踪输入和输出，因此它们的运行包括请求和响应负载，除非您关闭跟踪。
* 构建生成现在需要所选模型的 API 密钥。 “生成”按钮将保持禁用状态，直到将密钥保存在工作区或组织中，并且现有密钥满足要求而无需重新输入。
* 工具包替换了“工具”页面、API 路由和审核事件中的 MCP 网关，并且现有的 `/gateways` URL 和 `?view=gateways` 链接继续工作。您现在可以根据请求使用 `POST /v1/managed-tools/kits/{kit_id}/tool-refresh` 刷新工具包的工具。
* 工作区管理员现在可以在 **工作区工具** > **配置文件** 中创建工具凭证配置文件，为配置文件连接一次 OAuth 和 API 密钥服务器，并让代理通过发送 `X-LangSmith-Profile` 标头而不是充当用户来调用这些工具。* 代理构建器现在始终将您的原始请求传递给新代理：当您单击“**创建代理**”时，该请求将被预先填充为新代理的第一条消息，因此您不再需要重述它。
* 线程读取超时现在返回 504 网关超时而不是通用 500，已知太大的线程立即返回 422，而不是再次超时。
* Pylon 集成现在包含一个 `pylon_get_issue_messages` 工具，因此客服人员可以阅读有关问题的完整消息线程，包括客户回复和内部注释，而不仅仅是开头消息。
* Slack 中失败的代理运行现在在错误消息下包含一个脚注，链接到该运行的 LangSmith 跟踪。该链接适用于有权访问工作区的人员，并且线程中的其他人仍然会像以前一样看到错误。
* 在 OIDC SSO 组织中运行的队列现在会收到您的身份提供商访问令牌，包括在没有用户在场的情况下计划和触发的运行，并且令牌到期时会自动续订。

* 重新加载代理聊天页面不再通过加载和加载状态多次闪烁线程列表。现在，侧边栏在获取线程之前等待代理作用域完成加载，因此列表会稳定一次。
* 舰队代理现在在打开工具的参考文档之前使用 find\_tools 或 /tools 列表发现工具，因此他们不再浪费时间读取不存在的猜测工具文件名。
* Fleet Fast 模型层 (`gpt-5.4-mini`) 现在以中等推理速度（而不是低推理速度）运行，从而提高了较难任务的响应质量。* [templates](/langsmith/fleet/templates) 库现在以带有英雄插图的大卡片形式提供执行助理和软件工程师模板，每个模板都显示代理自己的图标。
* 代理配置面板中连接内的每个工具现在都有删除操作（悬停时显示垃圾按钮，与连接删除相匹配），而不是开/关开关。该开关意味着可逆切换，但关闭工具实际上会将其从代理中删除，因此控件现在反映了它的作用。
* 在澄清悬而未决的问题时发送聊天消息可能会导致运行失败并导致线程卡住。现在，自由文本会在继续之前正确地驳回待处理的请求。
* 在 Agent Builder 聊天中，技能块的“添加技能”菜单现在可打开浏览工作区、创建技能和从 URL 导入对话框。之前选择的选项更改了 URL，但没有出现任何内容。
* 现在，在 Fleet 中打开代理总是会开始新的聊天，而不是跳到最近的线程。过去的对话仍然可以在线程侧边栏中找到。* 当从模板创建的代理进行自我介绍时，它会将学到的内容直接写入自己的内存中，而不是暂停以等待每个文件的批准。其他线程中的内存写入仍然首先询问。
* 包含引号、冒号或多行的技能描述现在可以正确解析和存储，并且导入或编辑技能会保留其所有 frontmatter，而不是删除许可证或允许的工具等字段。
* 添加连接对话框现在将 Arcade MCP 服务器分组在专用 Arcade 部分下，因此它们很容易找到，而不是列在“其他”下。
* 舰队模型选择器现在将服务的 LCU 计费模型（Fast、Pro、Max）与按运行计费的自带模型分开分组，从而使每个选项的定价模型更加清晰。
* Agent Builder 中的紧凑型 Fast/Pro/Max 模型选择器现在在其关闭的触发器上显示模型图标，与完整模型选择器相匹配。
* 当组织达到每月队列使用限制时，错误现在会指示用户升级其计划以继续。
