# 创建注释队列项状态

/langsmith/langsmith-platform-openapi.json 发布 /api/v1/platform/annotation-queues/items/{queue_item_id}/status
记录 RUN 或 THREAD 注释队列项的调用者的审阅者状态。空状态会重新显示该审阅者的项目。
