# 获取注释队列项的位置

/langsmith/langsmith-platform-openapi.json 获取 /api/v1/platform/annotation-queues/{queue_id}/items/{item_id}/placement
将 RUN 或 THREAD 项解析到其当前审阅部分和从零开始的位置以进行深度链接。
