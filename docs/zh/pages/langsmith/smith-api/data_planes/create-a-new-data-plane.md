# 创建一个新的数据平面

/langsmith/langsmith-platform-openapi.json 发布 /orgs/current/data-planes
创建一个新的数据平面对象。保留渲染的数据平面规范，并返回 202，数据平面处于 status=requested 状态。需要启用 BYOC 的组织和组织管理员。
