# 删除数据平面

/langsmith/langsmith-platform-openapi.json 删除 /orgs/current/data-planes/{id}
验证存储的客户 AWS 角色是否具有删除权限，删除链接的工作区，并开始异步取消配置调用者组织拥有的数据平面。需要为组织和组织管理员权限启用 BYOC。
