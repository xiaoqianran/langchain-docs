# 获取服务器信息

/langsmith/langsmith-platform-openapi.json 获取 /api/v1/info
返回有关当前 LangSmith 部署的信息：版本、
实例功能标志、批量摄取限制和最大 SDK 版本。
默认未认证；设置 FF_INFO_ENDPOINT_AUTH_REQUIRED=true 以要求身份验证。
