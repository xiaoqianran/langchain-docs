# 更新入职状态字段

/langsmith/langsmith-platform-openapi.json 把 /api/v1/me/onboarding_state/{field}
更新当前用户的特定入职完成字段。

有效字段：
- 追踪完成时间
- lgstudio_completed_at
- 游乐场完成时间
- 评估完成时间
- 成功浏览次数
