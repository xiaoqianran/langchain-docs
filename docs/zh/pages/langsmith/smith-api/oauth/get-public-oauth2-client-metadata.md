# 获取公共 OAuth2 客户端元数据

/langsmith/langsmith-platform-openapi.json 获取 /oauth/client/{clientID}
返回已注册 OAuth2 客户端的显示元数据（名称、徽标、主页/术语/隐私链接）。由同意屏幕用来显示人类可读的客户端身份而不是原始 client_id。公共端点；仅公开非敏感显示字段。
