# 轮换 oauth 客户端密钥

/langsmith/langsmith-platform-openapi.json 发布 /api/v1/platform/oauth/clients/{id}/rotate-secret
为机密客户端生成新的客户端密码，使前一个客户端密码无效。新秘密仅显示一次。
