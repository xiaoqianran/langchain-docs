# 删除组织个人访问令牌

/langsmith/langsmith-platform-openapi.json 删除 /api/v1/orgs/current/personal-access-tokens/{pat_id}
删除个人访问令牌，完全删除记录。

调用者可以随时删除自己的令牌；组织管理员可以删除
任何会员的。
