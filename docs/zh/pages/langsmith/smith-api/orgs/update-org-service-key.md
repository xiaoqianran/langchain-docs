# 更新组织服务密钥

/langsmith/langsmith-platform-openapi.json 补丁 /api/v1/orgs/current/service-keys/{api_key_id}
就地更新 API 密钥的角色，无需轮换密钥。

仅限组织管理员 (ORGANIZATION_MANAGE)。适用于两者
/orgs/current/service-keys 中列出了组织范围和工作区范围的键。
