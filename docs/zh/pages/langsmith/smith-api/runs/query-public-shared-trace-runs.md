# 查询公共共享跟踪运行

/langsmith/langsmith-platform-openapi.json 发布 /api/v2/public/{share_token}/runs/query
返回由共享令牌标识的跟踪内的所有运行。共享令牌提供租户、项目和跟踪范围。

自托管部署需要 LangSmith `v0.16` 或更高版本。
