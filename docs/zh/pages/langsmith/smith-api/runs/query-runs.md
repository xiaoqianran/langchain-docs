# 查询运行

/langsmith/langsmith-platform-openapi.json 发布 /api/v2/runs/query
返回给定项目在最小/最大开始时间内运行的分页列表。支持过滤器、光标分页和`selects`选择要返回的字段。

自托管部署需要 LangSmith `v0.16` 或更高版本。
