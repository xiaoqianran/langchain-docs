# 分享跑步

/langsmith/langsmith-platform-openapi.json 发布 /api/v2/runs/{run_id}/share
创建或返回运行的共享令牌。子运行共享它们的跟踪根。

自托管部署需要 LangSmith `v0.16` 或更高版本。
