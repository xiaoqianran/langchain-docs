# 获取快照名称

/langsmith/langsmith-platform-openapi.json 获取 /api/v2/sandboxes/snapshots-by-name/{name}
获取快照名称及其下的每个标签，以及每个标签解析为的快照。要获取一个快照，请使用 /api/v2/sandboxes/snapshots/{snapshot_id}。
