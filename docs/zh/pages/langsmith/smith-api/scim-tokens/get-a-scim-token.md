# 获取 SCIM 令牌

/langsmith/langsmith-platform-openapi.json 获取 /api/v1/platform/orgs/current/scim/tokens/{scim_token_id}
通过 ID 检索当前组织的特定 SCIM 令牌。不返回完整的令牌值。
