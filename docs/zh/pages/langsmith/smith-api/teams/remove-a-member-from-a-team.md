# 从团队中删除一名成员

/langsmith/langsmith-platform-openapi.json 删除 /api/v1/platform/orgs/current/teams/{team_id}/members/{identity_id}
从团队中删除组织成员以及工作区身份
团队为他们录制。当身份不是成员时也会返回 204。
需要与添加成员相同的权限。
