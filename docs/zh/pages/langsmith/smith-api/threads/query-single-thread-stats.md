# 查询单线程统计信息

/langsmith/langsmith-platform-openapi.json 获取 /api/v2/threads/{thread_id}/stats
计算项目中单个线程的聚合统计数据（轮次计数、延迟百分位数、令牌/成本总和以及详细细分）。

自托管部署需要 LangSmith `v0.16` 或更高版本。
