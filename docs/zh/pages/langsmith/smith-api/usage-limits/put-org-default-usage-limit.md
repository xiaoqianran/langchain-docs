# 设置组织默认使用限制

/langsmith/langsmith-platform-openapi.json 把 /api/v1/usage-limits/org/default
为新工作区设置组织的默认每月跟踪限制；使用 `apply_to`，还可以更新现有工作区，而不受自身限制。
