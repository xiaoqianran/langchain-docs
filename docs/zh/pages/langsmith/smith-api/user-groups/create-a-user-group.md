# 创建用户组

/langsmith/langsmith-platform-openapi.json 发布 /api/v1/platform/orgs/current/user-groups
创建组织范围内的用户组。需要组织：用户组：管理。工作空间范围
此处未创建用户组：授予组织范围内的用户组访问权限
工作空间在那里创建其工作空间范围的用户组，因此工作空间_id 和
Parent_user_group_id 返回 400。
