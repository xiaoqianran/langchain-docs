# 获取用户组

/langsmith/langsmith-platform-openapi.json 获取 /api/v1/platform/orgs/current/user-groups/{user_group_id}
获取组织中的一个用户组。
组织范围的用户组需要organization:user-groups:read。
工作区范围内的用户组需要在其工作区中工作空间：用户组：读取。
