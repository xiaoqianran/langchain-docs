# 获取一个用户

/langsmith/langsmith-platform-openapi.json 获取 /api/v1/platform/sessions/{session_id}/users/{user_id}
返回应用程序的一名用户及其在跟踪项目中的特征。对路径中的`user_id`进行URL编码，以便其中的`/`作为`%2F`发送。
