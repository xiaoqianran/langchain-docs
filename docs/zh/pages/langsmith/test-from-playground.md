# 从 Playground 进行测试

无需编写代码即可在 LangSmith Playground 中的数据集上测试提示和模型配置。

[Playground](/langsmith/prompt-engineering-concepts#playground) 提供了一个用于迭代和测试提示和模型配置的接口。通过一系列输入测试提示或模型配置，看看它在不同上下文或场景中的得分如何，而无需编写任何代码。

在 Playground 中您可以：

* 更改正在使用的型号。
* 更改正在使用的提示模板。
* 更改输出模式。
* 更改可用的工具。
* 输入输入变量以运行提示模板。
* 通过模型运行提示并观察输出。

要在数据集上测试提示或模型配置并对结果进行评分，[run an evaluation from the Playground](/langsmith/run-evaluation-from-playground)。

<Callout type="info" icon="feather">
  使用 Playground 中的 [Chat](/langsmith/chat) 优化提示、生成工具并在 AI 辅助下创建输出模式。
</Callout>
