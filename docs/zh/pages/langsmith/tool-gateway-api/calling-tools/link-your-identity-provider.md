# 链接您的身份提供商

/langsmith/tool-gateway-openapi.json 把 /v1/managed-tools/oidc-connection
链接此工作区中已启用的身份提供程序，以便其访问令牌可以对 MCP 调用进行身份验证，从而替换任何当前链接。需要工作区：集成：管理。以您自己的身份打电话。
