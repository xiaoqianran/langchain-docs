# 存储配置文件凭据

/langsmith/tool-gateway-openapi.json 把 /v1/management-tools/profiles/{profile_id}/servers/{id}/credential
存储或替换秘密 MCP 服务器的配置文件标头凭据。需要服务器的工作区：凭据：管理和 mcp-服务器：调用。以您自己的身份打电话。值永远不会返回。
