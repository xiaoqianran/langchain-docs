# 用 AI 写下你的提示

提示画布使法学硕士可以轻松编辑提示。这使您可以更快地迭代长提示，也可以更轻松地对提示进行总体样式或色调更改。您可以通过单击提示中任何消息上的发光棒来进入提示画布：

![Prompt canvas open](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-open.gif?s=480b38abe2797436e0b7969e2d961e23)

## Chat sidebar

您可以使用聊天侧边栏询问有关提示的问题，或以自然语言向法学硕士提供如何重写提示的说明。

![Prompt canvas rewrite](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-rewrite.gif?s=91ba55b2e7b1e3a18a799265250dedb0)

> [!注意]
>
> 您还可以直接编辑提示 - 您**不需要**使用法学硕士。如果您知道要进行哪些编辑并且只想直接进行编辑，这非常有用

## Quick actions

只需单击鼠标即可快速更改提示的阅读级别或长度：

![Prompt canvas quick actions](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-quick-actions.gif?s=6d2bb4ee78ec98fe551ce7f1a0e94ad9)

## Custom quick actions

您还可以保存自己的自定义快速操作，以便于在 LangSmith 中处理的所有提示中轻松使用：

![Prompt canvas custom quick action](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-custom-quick-action.gif?s=3fd706f2fdd87abe339f83a2639ce708)

## Diffing

您还可以通过选择画布右上角的差异滑块来查看每个版本的提示之间的具体差异：

![Prompt canvas diff](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-diff.gif?s=be6259e6ac773c4a01c5b1ac4fe79e92)

## 保存和使用提示Lastly, you can save the prompt you have created in the canvas by clicking the "Use this Version" button in the bottom right:

![Prompt canvas save](https://mintcdn.com/langchain-5e9cc07a/H9jA2WRyA-MV4-H0/langsmith/images/prompt-canvas-save.gif?s=f54b0d1b6374e6b69750a6489c787172)
