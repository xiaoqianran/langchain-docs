# 用 AI 写下你的提示

提示画布使法学硕士可以轻松编辑提示。这使您可以更快地迭代长提示，也可以更轻松地对提示进行总体样式或色调更改。您可以通过单击提示中任何消息上的发光棒来进入提示画布：

<img alt="Prompt canvas open" />

## 聊天侧边栏

您可以使用聊天侧栏询问有关提示的问题，或以自然语言向法学硕士提供如何重写提示的说明。

<img alt="Prompt canvas rewrite" />

<Note>
  您还可以直接编辑提示 - 您**不需要**使用法学硕士。如果您知道要进行哪些编辑并且只想直接进行编辑，这非常有用
</Note>

## 快速行动

只需单击鼠标即可快速更改提示的阅读级别或长度：

<img alt="Prompt canvas quick actions" />

## 自定义快速操作

您还可以保存自己的自定义快速操作，以便于在 LangSmith 中处理的所有提示中轻松使用：

<img alt="Prompt canvas custom quick action" />

## 比较

您还可以通过选择画布右上角的差异滑块来查看每个版本的提示之间的具体差异：

<img alt="Prompt canvas diff" />

## 保存和使用提示最后，您可以通过单击右下角的“使用此版本”按钮保存在画布中创建的提示：

<img alt="Prompt canvas save" />
