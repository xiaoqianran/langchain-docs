# 法学硕士整合

使用 LangChain JavaScript 与法学硕士集成。

> [!警告]
>
> **您当前所在的页面记录了文本完成模型的使用。许多最新和最受欢迎的型号都是[chat completion models](/oss/javascript/langchain/models)。**
>
> 除非您专门使用更高级的提示技术，否则您可能正在寻找[this page instead](/oss/javascript/integrations/chat/)。

[LLMs](/oss/javascript/langchain/models) 是将字符串作为输入并返回字符串作为输出的语言模型。
