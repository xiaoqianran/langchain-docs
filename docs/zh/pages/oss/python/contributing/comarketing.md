# 联合营销

LangChain 每月下载量超过 6000 万次，拥有大量构建 LLM 应用程序的开发人员。除了列出集成之外，我们的目标还在于突出高质量的教育示例，以激励开发人员并推进生态系统。

<Note>
  虽然我们偶尔会分享集成，但我们会优先考虑提供以下内容的内容：
  有意义的见解和最佳实践。我们的主要社交渠道是[Twitter](https://x.com/LangChain)和
  [LinkedIn](https://www.linkedin.com/company/langchain/)，我们在此突出显示最好的示例。
</Note>

### 我们很高兴推广的内容

<AccordionGroup>
  <Accordion title="Educational content" icon="school">
    博客、YouTube 视频和其他展示教育内容的媒体。请注意，我们更喜欢不是“这里是如何使用集成 XYZ”的内容，而是“这里是如何执行 ABC”的内容，因为我们发现这对开发人员更具教育意义和帮助。
  </Accordion>

  <Accordion title="End-to-end applications" icon="cube">
    对于想要构建的开发人员来说，端到端应用程序是很好的资源。我们更喜欢强调本质上更复杂/代理的应用程序，并且使用 [LangGraph](https://github.com/langchain-ai/langgraph) 作为编排框架。我们对涉及以下内容的任何事情都感到特别兴奋：

    * 长期记忆系统
    * 人机交互模式
    * 多代理架构
  </Accordion><Accordion title="Research" icon="flask">
    我们喜欢强调新颖的研究！无论是建立在LangChain之上的研究还是与之集成的研究。
  </Accordion>
</AccordionGroup>
